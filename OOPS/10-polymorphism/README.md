
# 10 - Polymorphism

Polymorphism is an important OOP concept in Java that means **"one thing, many forms."** It allows the same method name or reference to behave differently depending on the parameters or actual object.

## Types of Polymorphism

### 1. Compile-Time Polymorphism

Compile-time polymorphism is achieved using "method overloading".

The method to be executed is determined by the compiler during compilation.
