
# 9 - Inheritance

Inheritance is an OOP concept in Java where one class acquires the properties and methods of another class using the `extends` keyword.

## Topics Covered

- [ ] What is Inheritance — reusing properties and methods of another class
- [ ] Parent class and Child class
- [ ] `extends` keyword
- [ ] Single Inheritance — one child class extends one parent class
- [ ] Multilevel Inheritance — a class inherits from another derived class
- [ ] Hierarchical Inheritance — multiple child classes extend the same parent class
- [ ] Multiple Inheritance — why it is not supported directly using classes in Java
- [ ] Hybrid Inheritance — combination of different types of inheritance
- [ ] Method inheritance
- [ ] Reusability using Inheritance
- [ ] `super` keyword — accessing parent class members
- [ ] Advantages and limitations of Inheritance
