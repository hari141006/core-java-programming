# 1 - Java Basics

Starting point. These are the very first things you need to understand before writing any real Java program.

## Topics Covered

- [ ] How a Java program is structured — class and main method
- [ ] JVM, JRE, JDK — what each one does
- [ ] Variables and data types — int, double, String, boolean, char
- [ ] Type casting — widening and narrowing
- [ ] Operators — arithmetic, assignment, logical, relational, bitwise, unary
- [ ] Taking user input using Scanner and DataInputStream
- [ ] Format specifiers and printing output
